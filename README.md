# WordPress Quiz Plugin

A comprehensive WordPress plugin for creating and managing online quizzes with student tracking, security features, and admin reporting.

## Features

✅ **Student Registration & Tracking**
- Student enters name, mobile number, and email
- One attempt per student (prevents duplicate attempts)
- Popup warning for attempted re-attempts

✅ **Security Features**
- Tab-switch detection with warning
- Automatic test submission after 3 tab switches
- Full attempt history and logging

✅ **Quiz Management**
- CSV import for questions
- Custom timer for quizzes
- Multiple choice, true/false, and short answer questions

✅ **Admin Dashboard**
- View all student responses
- Generate detailed reports
- Export data
- Quiz analytics

## Installation

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the WordPress admin panel
3. Configure quiz settings in the admin panel

## Requirements

- WordPress 5.0+
- PHP 7.2+
- MySQL 5.6+
